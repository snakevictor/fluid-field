# Fluid Field waterfalls: every approach tried (D20-D59), honest history

Sources: docs/fluidfield/DECISIONS.md (D20-D59), LEARNINGS.md, `git log` on feature/fluid-field
(ce9e6a58e D23 .. c3a3e12b3 D59, about 95 waterfall commits in roughly 3 days, 2026-10-15..17),
scratchpad research/waterfall_techniques.md, ogfalls/report.md, and a grep of the current code.

Quote policy: user quotes below are copied from the decision log. **The phrase "this looked much
better already" does not appear anywhere in docs/fluidfield or in any commit message**; if the user
said it, it was never recorded. Praise is recorded only indirectly (see the Praise section).

### Cutting buried/underwater parts (D36-D40, D45, D47-D50, D52-D54, D56-D58)

-   D36 pixel discard under pools -> D38: discards left the pre-pass depth: "milky/white". Moved to **SV_ClipDistance** in Lighting + Utility VS.
-   D40: Utility.hlsl never got feature defines, so its clip never ran (tan); and pools were whole 4096u cells, so "under a pool" swallowed most of a fall. Found "by instrumenting, not guessing".
-   D44: clip used main camera instead of the pass's posAdjust (reflections).
-   Pool detection whack-a-mole: D40 (rock tests), D45 (engine water sampling), D50 (deep plunge pools), D52 (flood fill), D53 (flood ran under curtains because the top-down raster skipped near-vertical triangles: holes 529/532/533/536).
-   Ground cut depth whack-a-mole: D47 (cliff gaps: 2.5D 16u map put cliff faces under the cliff top), D48 (40 deep), D49 (back to 2, overhangs -> 120), D54 (BURIED_SOFT 4 on large triangles), D56 (per-vertex rays replace the map; test never fired), D57 (ray parity; 325/1188 inside), D58 (bilinear pool, clamp +-48, pool cut 8).
-   Fixed? Mostly: per-vertex parity cut and bilinear pool cut are the current state; the D57 open-edge reach (gap 603) was removed in D58 unfixed. Coarse triangles still limit where the cut line falls.
-   In code: ClipDistance, VertexClip (t123), ClipStep, pool map.

### Spray, fog, mist (D31, D33, D35, D37-D44, D47-D54)

-   Spray: changed in D31, D33, D35, D37, D47, D48, D49, D50, D51, D52, D53, D54. Oscillated on size/opacity/count (D47 blobs; D50 sparser; D51 "fewer was not the ask; better placement was") and source (drops, plunges, strikes, impacts, rock hits, seams, vanilla splash positions). User feedback mostly about colour ("spray and mist are blue"), size ("too big and too few"), translucency, origin ("they should always come from water"; "where the fall starts, where it ends, and in intersections"). Still in code; placement still heuristic.
-   Fog: D37 feed ground fog -> D38 own FallFog -> D39 from collisions -> D40 opaque wall -> D41 not visible afar -> D43 "violent" -> D44 55 ms GPU cut to 3.7 ms -> D50 white veils, off -> D51 removed ("the waterfall fog's implementation was shit ... remove this current version altogether"). Never fixed; gone.
-   Mist cards: off D49, gone D50.

### Whitening / foam on the falls (D34, D39, D42, D44, D46, D47, D58, D59)

Hue-true whitening (D39), lace foam (D42), neutral colours (D44), variance-preserving blend (D46, contrast matched vanilla in captures), colour-only boost (D47, normals sparkled), D58 boost removed where it marbled, D59 no boost + aeration with run time. Lace and aeration in code.

### Downhill rules (D44, D53, D54, D55)

No uphill (D44), always downstream / steep follows slope (D53), least flow 0.6 (D54), moderate slopes follow slope (D55). D56: "kept trading one failure for another because the flow's direction came from the wrong source: a top-down height map and the local slope, which arched, folded and curtained meshes defeat". All removed in D56.

### Translucency (D53-D56)

Lit surface has no NiAlphaProperty; borrowing 0x10ED makes it draw invisible; needs registering with the blended pass. **Never worked**; slider exists, default 0.

### Shallow-water coupling (D22, D35, D36, D44, D47, D48, D49, D54, D55, D56)

## 3. Recurring failure patterns

1. **Top-down (2.5D) data applied to vertical/folded sheets.** D24 SWE heightfield, D27 SWE, D28/D32 solve from above, D33 head, D34 course, D36-D49 ground-map cut (cliff gaps, overhang holes), D53 flood under curtains (raster skipped near-vertical triangles), D53-D55 downhill rules, D57 curtain marble. Only D56 (per-vertex rays, mesh +v) and D59 (UV-grid solve) left this frame.
2. **Low-poly vanilla triangles + per-vertex data.** D26 push tore triangles; D35 texture jumps at triangle edges; D54 BURIED_SOFT; D57 cut notches; techniques survey: a boulder is often smaller than one triangle. Subdivision/tessellation investigated (D48) but never built (the D31 subdivided copy was only for our own surface).
3. **Flowmap pulsing / resets / marble.** D20 steering flicker; D32 two-phase; D46 milky mid-blend -> contrast boost; D47 normals sparkle; D58 marble from two texture patches; D59 reset jump when fading one phase. Fixed (for now) only at D58/D59 after ~27 rounds.
4. **Engine pipeline traps found late.** Depth pre-pass EQUAL (D29); Utility shaders had no feature defines (D40); reflection camera posAdjust (D44); blended draw invisible (D53-D56, unsolved); async shader compile renders stale shaders for 5-10 s; include-only shader edits not recompiled.
5. **Measurement noise / acting before verifying.** D26-D28 work applied to overlay layers not the water (discovered D29); "texture runs along u" (LEARNINGS, D31) vs "v is downstream on 100% of area" (NIF dissection, D56) - a direct contradiction in the record; D56's rock test never fired; D56 capture took the falls' own collision as rock (14% of rays, under every fall, for ~30 decisions); D53 alpha switch did nothing on first run; D59 first bake called a third of curtains rock. Wins came when measured: D40 instrumenting, D44 GPU timing (55 ms fog), D46 captures A/B.
6. **Pool detection whack-a-mole** (D36, D40, D45, D50, D52, D53) because engine water planes are whole cells.
7. **Tuning oscillation** on spray (12 decisions) and cut depths (8+ values: 6, 8, 30, 40, 2, 120, 4, 20, 8) instead of fixing the source.
8. **Fog never converged** and was removed entirely (D37-D51).
